# 名刺ノート（ゆうせい専用の名刺アプリ）

紙の名刺をiPhoneで電子管理するための、自分専用のアプリです。

## 大事なこと

- **名刺のデータと写真は、iPhoneの中（Safariの保存場所）だけ** に保存されます。どこにも送りません。
- このフォルダ（プログラム）には名刺のデータは入っていません。
- 文字の読み取りは、iPhoneに最初から入っている無料の機能（テキスト認識表示・テキストをスキャン）を使います。
- 費用は0円です。

## 使い方（iPhone）

1. Safariでアプリのアドレスを開く。
2. 共有ボタン（□に↑）→「ホーム画面に追加」。ホーム画面のアイコンから開くと、データが消えにくくなります。
3. 右下の「＋」→ 名刺の写真を撮る。
4. 写真の文字を長押し →「すべてを選択」→「コピー」→ 下の枠に「ペースト」→「振り分ける」。
5. まちがっている欄を直して「保存」。
6. ときどき右上の「⋯」→「バックアップを書き出す」→「"ファイル"に保存」。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の形 |
| `style.css` | 見た目（色・大きさ） |
| `app.js` | 動き（保存・一覧・検索・バックアップ） |
| `parse.js` | 読み取った文字を、名前・会社・電話などに振り分ける |
| `sw.js` | 電波がなくても画面を開けるようにする |
| `manifest.webmanifest`・`icon-*.png` | ホーム画面のアイコンと名前 |
