# 名刺ノート（ゆうせい専用の名刺アプリ）

紙の名刺をiPhoneで電子管理するための、自分専用のアプリです。

## 大事なこと

- **名刺のデータと写真は、iPhoneの中（Safariの保存場所）だけ** に保存されます。どこにも送りません。
- このフォルダ（プログラム）には名刺のデータは入っていません。
- 文字の読み取りは、無料の読み取りソフト **Tesseract.js**（`vendor/`）がiPhoneの中で動かします。名刺の写真は外に出ません。
- 費用は0円です。

## できること

- 写真を撮る → 自動で文字を読み取り、名前・会社・役職・電話・携帯・メール・サイト・住所に振り分け
- うまく読めないときは、iPhoneの読み取り（写真の文字を長押し→コピー）をボタン1つで貼って振り分け
- 一覧と検索、「会社ごと」のまとめ表示（「株式会社〇〇」と「〇〇株式会社」は同じ会社にまとまる）
- 項目ごとの「コピー」、全部まとめてコピー
- 「iPhoneの連絡先に追加」（連絡先ファイル＝vCardを作って開く）
- バックアップの書き出し・読み込み

## 使い方（iPhone）

1. Safariでアプリのアドレスを開く。
2. 共有ボタン（□に↑）→「ホーム画面に追加」。ホーム画面のアイコンから開くと、データが消えにくくなります。
3. 右下の「＋」→ 名刺の写真を撮る → 自動で欄が埋まる（はじめての1回だけ、読み取りの準備に少し時間がかかります）。
4. まちがっている欄を直して「保存」。
5. くわしい画面の「iPhoneの連絡先に追加」→「新規連絡先を作成」。
6. ときどき右上の「⋯」→「バックアップを書き出す」→「"ファイル"に保存」。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の形 |
| `style.css` | 見た目（色・大きさ） |
| `app.js` | 動き（保存・読み取り・一覧・会社ごと・コピー・連絡先・バックアップ） |
| `parse.js` | 読み取った文字を、名前・会社・電話などに振り分ける |
| `sw.js` | 電波がなくても画面を開けるようにする |
| `manifest.webmanifest`・`icon-*.png` | ホーム画面のアイコンと名前 |
| `vendor/` | 読み取りソフト Tesseract.js 5.1.1（Apache-2.0）と、日本語・英語の読み取りデータ（小さい版） |
